# Outlaw: восстановленный Lua

[Скачать полный Lua](outlaw_deobfuscated.lua) · [Скачать архив со всеми материалами](outlaw_deobfuscated.zip)

Восстановлены все 386 функций приложения из `output_outlaw_beta (1).lua`.
Итоговый файл содержит 22 150 строк обычного Lua. Устранены виртуальный
диспетчер, массив регистров, шифрование инструкций и `goto`. Имена
локальных переменных сгенерированы, поскольку авторские имена в присланном
файле отсутствуют. Объекты с полем `.value` сохраняют общие переменные
замыканий и поведение исходных операций CLOSE.

В архив включены полный Lua, 40 раскодированных пресетов, указатель функций,
объяснение Experimental Predict и журналы проверок. Отдельные файлы:

- [Experimental Predict для меню gamesense](experimental_predict.lua)
- [Experimental Predict для исходной UI-обёртки](experimental_predict_module.lua)
- [Объяснение поведения Experimental Predict](experimental_predict_explanation.txt)
- [Указатель 386 функций](function_index.json)
- [Отчёт проверок и контрольные суммы](verification.json)

В присланной версии Experimental Predict создаёт список режимов и меняет
его видимость при выборе раздела Rage Bot. Связанного с этим списком
алгоритма предсказания не обнаружено. Создание элемента находится в
функции 242, обработчик видимости — в функции 293.

Пройдены 132 проверки выбранных функций, замыканий, циклов, аргументов,
метатаблиц и извлечённого UI. Итоговый файл проходит проверку синтаксиса
Lua 5.1 и 5.3. Полное выполнение в gamesense не проверялось: необходимы
LuaJIT, игровые API и внешние модули приложения. Проверки отдельных
функций не доказывают эквивалентность всех путей выполнения.
