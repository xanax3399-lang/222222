Sauron resolver — читаемый исходник GameSense / CS:GO

Основной файл: sauron_resolver_full_source.lua.
sauron_resolver_source.lua содержит ту же версию для совместимости старой ссылки.
Загружать нужно один из этих файлов. Исходный обфусцированный скрипт
и предыдущие восстановления одновременно не загружайте.

Зависимости: gamesense/csgo_weapons и vector.
Меню: RAGE / Other / [sauron beta] Enhanced resolver.

Исходник полностью изложен обычным Lua: именованные функции и переменные,
обычные условия и циклы. Убраны интерпретатор PSU, поток инструкций,
десериализатор, goto, имена регистров L/A, pack_results и временные цепочки.
Открыты резольвер, история игроков, обработчики выстрелов, фильтр оружия,
меню, уведомления и ESP. Авторские имена/комментарии не сохранились;
использованные имена и комментарии восстановлены по назначению.

По сравнению с первой декомпиляцией уточнены две ветки по исполнению
оригинальной VM: выбор категории оружия и unknown при неактивном резольвере.
Это восстановление поведения оригинала, а не усиление алгоритма резольвера.
Удалён неиспользуемый пролог-приманка, который расходовал math.random.

Проверки: 220 сравнений с исходным PSU исполнением в изолированном LuaJIT.
Сравниваются вызовы API, значения/возвраты, состояние и история игроков;
проверены UI, трассировки, скорости 0..250, duck/ground, позы, тики,
фильтры оружия, попадания/промахи, уведомления и ESP. Нет сетевых запросов
или обращения к памяти игры при проверке. Синтаксис Lua 5.1 и LuaJIT пройден.
Отчёт и SHA256 исходника: full_validation.json. CS:GO здесь не запускалась.

Инструменты и оригинальный файл находятся в research. Воспроизведение:
Python 3.12+, Java 21+, pip install -r research/requirements.txt
python research/rebuild.py
Сначала восстанавливается промежуточная декомпиляция, затем вручную
структурированный полный исходник проверяется против оригинальной VM.
