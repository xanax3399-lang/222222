Sauron resolver — восстановленный исходник GameSense (CS:GO)

Загрузка: установите sauron_resolver_source.lua в папку Lua GameSense.
Зависимости оригинала: gamesense/csgo_weapons и vector.
Меню: RAGE / Other / [sauron beta] Enhanced resolver.
Оригинал одновременно с восстановленной версией загружать не нужно.

Что снято:
- Сжатый/закодированный поток PSU Obfuscator 4.0.A.
- Десериализатор, таблицы виртуальных инструкций и интерпретатор PSU.
- Неиспользуемый helper и пролог с 200 строками-приманками и 2000
  итерациями генерации неиспользуемого текста. Их расход math.random удалён.
- Переходы goto преобразованы в обычные условия; восстановлены замыкания,
  циклы, varargs и многозначные возвраты с сохранением nil.

Имена API и основных функций даны по назначению. Исходные авторские имена
локальных переменных и комментарии обфускатор не сохранил; оставшиеся
A0_2 / L3_2 — обычные локальные переменные, не виртуальные инструкции.
pack_results — небольшой обычный Lua helper для многозначных возвратов.

Извлечена 31 функция исходного потока, включая один удалённый неиспользуемый
helper пролога. Игровая логика сохранена. Это восстановление исходного
скрипта, новых возможностей резольвера здесь нет. Внешний payload из сети
этот файл не загружает; модули require остаются зависимостями GameSense.

Проверка: 84 сравнения оригинального PSU исполнения, восстановленного Lua
до оптимизации и итогового Lua на контролируемых заглушках GameSense.
Сравнивались настройки UI, углы, трассировки, движение, setup_command,
попадания в голову/тело, spread/unknown, история игроков, уведомления,
сбросы раунда/смерти/подключения и ESP. Отчёт validation.json.
Проверка синтаксиса LuaJIT пройдена. В самой CS:GO сборка не проверялась.

Воспроизведение: Python 3.12+, Java 21+, pip install -r research/requirements.txt,
затем python research/rebuild.py. В research приложены исходный обфусцированный
файл и инструменты восстановления, включая unluac с лицензией.
