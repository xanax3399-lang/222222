# Emberlash — читаемый исходник из присланной декомпиляции

`emberlash_source.lua` содержит весь исполняемый код, который есть в загруженном
`emberlash_decompiled.lua`: 2 300 функций и основной chunk. Это восстановленный
читаемый текст присланного файла, а не найденный авторский проект.

## Что с виртуальной машиной

В присланном файле уже находится обычный Lua-код с прямыми функциями и вызовами
GameSense. Диспетчер VM Luraph и её виртуальные инструкции в нём не обнаружены.
Снимать VM в этом проходе не потребовалось. Исходный защищённый Luraph-файл
не предоставлен: проверить, не потерял ли предыдущий декомпилятор что-либо
ДО появления этого файла, по этой загрузке невозможно.

Встроенный x86-ассемблер, машинные хуки и сетевой bit buffer — функциональные
части самого Emberlash. Они сохранены. Таблица `a[число]` в начале — таблица
179 функций API хоста, не VM. Использования подписаны комментариями с именами API.

## Что сделано

- По лексическим областям переименованы 14 428 локальных переменных/параметров;
  обновлён 68 801 токен использования. Понятные исходные имена сохранены.
- Имена модулей и подсистем выведены из импортов, методов, полей и мест вызова.
  Это осмысленные восстановленные имена, не утверждение об авторских именах.
- Убраны огромные отступы, добавлены заголовки подсистем. Области `do/end`
  сохранены: они участвуют в сроках жизни локальных переменных и замыканий.
- Сохранены строки, константы, пресеты, функции, порядок вычислений и управления.
  Имеющиеся в загрузке offline-адаптеры также сохранены.
- Составлены указатели функций и переменных с номерами строк.

## Проверка полноты

До и после восстановления выполнена КОМПИЛЯЦИЯ через LuaJIT, без запуска
самого скрипта и его native/игровых колбэков. Сериализованный байткод полностью
совпал в детерминированном режиме `string.dump(function, "sd")`:

- 2 301 прототип, включая основной chunk;
- 1 620 315 байт одинакового байткода;
- SHA-256 байткода: `23aa7acd56147654ed53937b0eff76263b6617cd49c07ee1dc699c7d987b06c2`.

Режим `s` убирает отладочные имена/строки, режим `d` фиксирует порядок
сериализации ключей табличных констант. Инструкции, константы, связи дочерних
функций и захватов переменных при этом сверяются целиком.

Файл уменьшился с 12 663 260 до 3 251 822 байт в основном из-за отступов;
количество функций не уменьшилось. Точные хеши и результаты — в `validation.json`.
Это проверка сохранения присланного кода, не проверка его поведения в матче.

## Зависимости для запуска

Целевая среда — GameSense/CS:GO и LuaJIT. В файле есть 13 импортов:
`ffi`, `bit`, `vector`, `gamesense/pui`, `gamesense/clipboard`,
`gamesense/base64`, `gamesense/msgpack`, `gamesense/antiaim_funcs`,
`gamesense/csgo_weapons`, `gamesense/entity`, `gamesense/trace`,
`gamesense/surface`, `gamesense/images`.

Загрузка содержит ссылки на 131 локальный файл `emberlash/assets/...`
общим объёмом 68 647 669 байт. Самих файлов изображений пользователь не приложил;
они не включены в этот архив. Полный перечень путей, ожидаемых размеров и URL —
в `DEPENDENCIES.json`. Ссылки не доказывают доступность удалённых ресурсов.

## Файлы

- `emberlash_source.lua` — весь читаемый восстановленный код.
- `original.lua` — точная копия присланного `emberlash_decompiled.lua`.
- `FUNCTIONS.csv` — все 2 300 функций: имя, строки исходника и параметры.
- `SYMBOLS.csv` — соответствие исходных и восстановленных локальных имён.
- `API_MAP.json` — расшифровка 179 индексов таблицы API.
- `DEPENDENCIES.json` — импорты и перечень отсутствующих изображений.
- `validation.json` — результаты сравнения байткода и хеши файлов.
- `tools/` — воспроизводимые инструменты анализа, переименования и проверки.
- `SHA256SUMS.json` — контрольные суммы файлов архива.

## Воспроизведение

Проверено с Python 3.12. Из распакованной папки:

```sh
python -m venv .venv
.venv/bin/python -m pip install -r tools/requirements.txt
.venv/bin/python tools/recover.py
.venv/bin/python tools/verify.py .
```

На Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.
Инструменты разбирают и компилируют Lua, не исполняя его основной chunk.
