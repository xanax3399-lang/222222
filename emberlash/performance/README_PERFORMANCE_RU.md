# Emberlash — версия с облегчённым HUD

Установка: полностью закройте CS:GO после предыдущей версии, замените Lua-файл
и загружайте только `emberlash_optimized.lua`. Две копии Emberlash одновременно
загружать не следует: в скрипте есть нативные хуки и обработчики событий.

## По умолчанию

В `LUA → A` включён `Emberlash: lightweight HUD`. Режим отключает размытие
и тени панелей, сохраняя панели, текст, индикаторы и обычную отрисовку.
Для прежнего оформления снимите галочку. Кэши и остальные оптимизации
продолжат работать. Переключение этого пункта не требует перезапуска.

## Что оптимизировано

- Общие размеры экрана для HUD запрашиваются один раз за кадр.
- Повторяющиеся измерения одинакового текста/флагов в HUD объединяются.
  Кэш ограничен 512 записями. Каждый результат действителен только в текущем
  кадре; смена кадра обновляет метрики, откат framecount очищает кэш.
  Необычные аргументы и вариативные вызовы передаются исходному API.
- Окна HUD используют общий снимок мыши и меню за кадр, сохраняя собственное
  состояние перетаскивания и предыдущего нажатия.
- Объекты Panorama для blur/теней создаются при первом использовании эффекта.
  В лёгком режиме они вообще не создаются, пока оформление не включено.
- У пустых пулов эффектов выполняется один проход скрытия. Следующие пустые
  кадры пропускают обход до появления новых элементов.

Рейджбот, анти-аимы, трассировки, нативные хуки, число проб, DT и автособытия
игровых функций этим изменением не перенастраивались. Проверена побайтовая
неизменность соответствующего исходного участка. Модуль анимаций сохранён
в прежнем виде.

## Проверки

Полный файл компилируется в LuaJIT. Выделенные реальные функции исходника
исполнялись с управляемыми API хоста, без загрузки его машинных хуков:

- 31 209 сравнений результатов анимаций и 2 386 вызовов пользовательского easing;
- 1 440 сравнений состояния окон: чтений ввода 1 440 → 120 для 12 окон / 120 кадров;
- 100 одинаковых запросов измерения в одном кадре → 1 исходный вызов API;
- проверены смена кадра, разрешения/метрик между кадрами, откат framecount,
  лимит кэша, разные флаги, строки с нулевыми байтами и вариативные вызовы;
- проверены отключение/включение эффектов, повторное использование их объектов,
  исходные аргументы геометрии и скрытие ранее видимых элементов.

Это проверки компонентов, а не замер FPS на GTX 1050 или в настоящем матче.
Конкретный прирост FPS не измерялся. Статистика и хеши —
в `optimization_validation.json`.

## Зависимости

Библиотеки GameSense и папка `emberlash/assets` нужны те же, что и исходной
декомпиляции. В загруженном пользователем файле самих изображений не было.
Их перечень и импорты сохранены в `DEPENDENCIES.json`.

## Исходники изменения

`tools/optimize.py` воспроизводит оптимизированный файл из неизменённого
`../emberlash_source.lua`. `tools/validate.py` выполняет проверку компонентов.
Они находятся в репозитории рядом с этой версией. Для запуска нужны зависимости
из `../tools/requirements.txt` исходного пакета.

Эта версия меняет исполняемый код HUD, поэтому утверждение о совпадении всего
байткода из исходного пакета декомпиляции относится только к тому пакету.
Здесь сохранность игровых частей и поведение изменённых компонентов проверяются
отдельным отчётом.
