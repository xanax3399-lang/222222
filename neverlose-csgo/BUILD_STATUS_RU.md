# Neverlose CS:GO: сборка GitHub Actions

Полный комплект DLL + injector собран на Windows в GitHub Actions и опубликован в GitHub Release:

- [Скачать ZIP](https://github.com/xanax3399-lang/222222/releases/download/neverlose-csgo-845188ab71a746c07ea89a5bd13f4a83b9efd1c7/neverlose-csgo-windows.zip)
- [Сборка и проверки](https://github.com/xanax3399-lang/222222/actions/runs/41438689245)

В ZIP находятся `neverlose.dll`, `injector.exe`, README, лицензия ImGui и отчёт проверки ресурсов. Локальный сервер x64 встроен в инжектор x86. C++ runtime подключена статически; отдельные файлы сервера и C++ runtime рядом с инжектором не требуются. Целевая система — Windows 10/11 x64, игра — CS:GO Legacy x86.

## Запуск

1. Распаковать DLL и EXE в одну папку.
2. Запустить CS:GO Legacy в оконном режиме или без рамки.
3. Запустить `injector.exe` и оставить его окно открытым во время игры.
4. Insert/Home открывает новый интерфейс. Страница Ragebot возвращает к прежнему игровому редактору настроек.

`injector.exe --server-only` запускает встроенный сервер без игры и загрузки DLL. Enter останавливает принадлежащий инжектору сервер. Если подходящий сервер уже работал, инжектор использует его и не завершает чужой процесс.

В самом CS:GO эта сборка **ещё не проверялась**. Успех CI подтверждает сборку и перечисленные проверки, а не игровой цикл или точность Ragebot. Возврат Windows LoadLibrary также не доказывает завершение внутренней инициализации ядра.

## Что проверено на Windows

- Собраны настоящие DLL и EXE с MSVC v143; сервер — Rust 1.88.
- Побайтно проверены ресурс исходного ядра в DLL и ресурс сервера в инжекторе.
- Запущен сервер: HTTP health, API конфигов, настоящая встроенная Lua-библиотека и WSS handshake с проверкой сертификата.
- Запущен **сам injector.exe** в режиме `--server-only` из отдельной временной папки. Он извлёк встроенный сервер, дождался готовности и остановил его при выходе.
- Прошли C++ тесты истории/точек и отрисовка четырёх страниц меню с кликами Close, навигация, Save и Reset.

## Интерфейс

Первый вариант Dear ImGui/D3D9: боковая панель, фиолетовый акцент, прозрачность, масштаб текста, водяной знак, таймер и локальный профиль `%LOCALAPPDATA%/NeverloseCSGO/interface.json`. Интерфейс использует отдельное прозрачное окно; эксклюзивный fullscreen не поддерживается.

Все переключатели Ragebot ещё не перенесены в новый интерфейс. Для них доступен существующий редактор. Это первая версия оформления, а не полная копия меню CS2.

## Повторение сборки

Из Visual Studio Developer PowerShell с установленными Windows SDK, MSVC v143 и Rust >= 1.88:

```powershell
.\build_windows.ps1 -PlatformToolset v143
```

Скрипт сначала собирает сервер, затем встраивает его ресурсом в инжектор и собирает DLL Win32. Ветку `codex/neverlose-csgo-build` также собирает `.github/workflows/neverlose-csgo.yml`.

Зашитый сайт-токен из предоставленного архива не опубликован и не включён в новую DLL. Необязательная старая интеграция может получить значение из `NL_WEBSITE_TOKEN` во время запуска. Значение этой переменной нельзя коммитить.
