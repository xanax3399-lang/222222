# DLL, встроенный сервер и новое меню CS:GO

## Текущее состояние

Собраны Windows `Release/injector.exe` (x86) и сервер (x64). Сервер и его LLVM-библиотека включены в ресурсы инжектора; отдельный сервер рядом с инжектором не нужен. Проверка PE-ресурсов сравнивает оба встроенных файла побайтно с результатом сборки. Требуется Windows 10/11 x64.

**Полная `neverlose.dll` ещё не собрана.** Исходный клиент использует Microsoft SDK/PHNT и MSVC-расширения. Microsoft SDK не удалось загрузить: запрос отклонён сетевым прокси. MinGW подходит для нового инжектора и файлов интерфейса, но не заменяет SDK для всего исходного клиента. В конфигурационный черновик среды добавлены `download.visualstudio.microsoft.com` и `download.microsoft.com`. Сохранение черновика не применяет эти настройки; для продолжения облачной сборки требуется сохранить и опубликовать настройки среды. Запуск DLL, EXE и интерфейса в Windows/CS:GO в этой среде не проверен.

## Что изменено

- `injector/main.cpp` заменён новым загрузчиком: находит только `csgo.exe`, проверяет архитектуру DLL, извлекает и проверяет встроенный сервер, ожидает настоящий HTTP health-ответ и WS-порт, загружает DLL и удерживает собственный сервер до закрытия игры. Закрытие инжектора завершает принадлежащий ему сервер через Job Object. Уже работавший сервер не завершается.
- Новый инжектор не меняет настройки защиты Windows, не стирает PE-заголовки, не запускает старый watchdog и не исправляет код системных библиотек. Вызовы старого удалённого сервиса из старого инжектора не перенесены. Это не проверка или изменение прав на исходный коммерческий продукт; используется предоставленная локальная серверная часть.
- `server/rust-server/build.rs` исправлен: встроенные Lua-файлы теперь берутся по действительным путям вместо пустого пути каталога. Добавлен `/health`. TLS работает с явно выбранным Ring-провайдером вместо сборки неиспользуемого второго криптопровайдера; проверка TLS не отключена.
- `neverlose/ui/` содержит настоящий Dear ImGui-интерфейс с четырьмя страницами, фиолетовым акцентом, настройкой прозрачности/масштаба, водяным знаком, таймером и локальным профилем `%LOCALAPPDATA%/NeverloseCSGO/interface.json`.
- Новый интерфейс подключён в `setup_hooks.cpp` и открывается через Insert после перехвата существующего объекта меню. Home открывает его независимо. При недоступности нового окна остаётся прежний обработчик. Кнопка Open game settings возвращает к существующему редактору, потому что все настройки Ragebot ещё не перенесены в новый интерфейс. Новых фиктивных переключателей прицеливания нет.
- Интерфейс использует отдельное прозрачное D3D9-окно в процессе клиента. Первая версия требует **оконного режима или режима без рамки**; эксклюзивный fullscreen не поддерживается. Это начальный интерфейс, а не полная копия меню Neverlose CS2.

## Проверено

- Четыре страницы отрисованы настоящим ImGui; проверены клики Close, навигация, Save и Reset. `preview/menu-page-2.png` — программная отрисовка реальных draw lists, не скриншот работы игры.
- Функциональный серверный тест: HTTP health, API конфигов, выдача настоящей встроенной Lua-библиотеки и WSS handshake с проверкой сгенерированного сертификата. Windows-EXE собран из того же исходника, но его запуск не проверен.
- Один новый Rust-тест встроенной библиотеки проходит. Существующие C++ тесты истории/точек проходят; 4066 сравнений восстановленного предиката с x86-инструкциями также проходят.
- Инжектор и файлы Windows-интерфейса скомпилированы LLVM-MinGW. Полный клиент остановился на несовместимости SDK-заголовков, а не был подменён тестовой DLL.

## Сборка полного комплекта на Windows

Нужны Visual Studio Build Tools (C++ x86/x64, Windows SDK), MSVC v143 или v145 и Rust >= 1.88. Из Developer PowerShell:

```powershell
.\build_windows.ps1 -PlatformToolset v143
# либо -PlatformToolset v145 для соответствующих Build Tools
```

Скрипт сначала собирает x64-сервер, затем DLL и инжектор Win32. Итоговые пользовательские файлы — `Release/neverlose.dll` и `Release/injector.exe`; промежуточный server.exe нужен только при сборке ресурса. Существующий LLVM-runtime в Release не встраивается MSVC-сборкой.

После успешной сборки: запустить CS:GO Legacy в окне/без рамки, положить DLL рядом с инжектором и запустить инжектор с тем же уровнем привилегий. Оставить окно инжектора открытым. `injector.exe --server-only` проверяет запуск встроенного сервера отдельно от игры; Enter завершает собственный сервер.

## Повторение проверок

```sh
bash recovery/run_checks.sh
# Меню (Linux):
g++ -std=c++17 -O1 -Ivendor/imgui tests/menu_render_test.cpp neverlose/ui/menu_view.cpp vendor/imgui/imgui.cpp vendor/imgui/imgui_draw.cpp vendor/imgui/imgui_widgets.cpp vendor/imgui/imgui_tables.cpp -o recovery/build/menu_render_test
recovery/build/menu_render_test preview
# Сервер:
cd server/rust-server
cargo test --locked
cargo build --locked
cd ../..
python3 tests/server_smoke.py server/rust-server/target/debug/neverlose-server
# Ресурсы Windows-артефактов:
python3 tests/check_release.py Release
```

Сетевой smoke-тест требует свободных loopback-портов 30030/30031. Он запускает и завершает только свой процесс. Отчёты и вывод сборки находятся в `recovery/`.
