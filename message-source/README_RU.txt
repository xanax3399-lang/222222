message.lua — восстановление локального загрузчика Acatel

ВАЖНО О ПОЛНОТЕ
Присланный message.lua — загрузчик, а не весь основной скрипт.
Извлечены все 52 локальных прототипа функций PSU. Восстановленный код
не содержит виртуальной машины, потока инструкций MATRIX, его декодера
или диспетчера. Это исходник имеющегося локального кода.
Основное приложение отсутствует: оно получается через HTTP, берётся
из поля lua ответа, затем запускается через loadstring. Публичный
module.txt также загружается отдельно. Эти данные в файле не содержатся.
Запрос публичного Gist из облачной среды получил CONNECT 403 от прокси;
ответы серверов приложения не получены. Обход авторизации не выполнялся.

ФАЙЛЫ
message_source.lua — вся доступная программа: исходная внешняя обёртка
с подменами API плюс восстановленный отложенный загрузчик.
message_loader_source.lua — внутренняя часть отдельно для изучения.
message_wrapper_source.lua — внешняя обёртка отдельно для изучения.
Не загружайте все три одновременно: две части уже входят в message_source.lua.
Отдельные компоненты нужны для чтения, а не для совместной загрузки.

ЧТО ВОССТАНОВЛЕНО
MD5, Base64, ROT13/ROT47, XOR и кодирование полей запроса;
встроенные FFI-объявления и Steam HTTP клиент;
получение интерфейсов и данных адаптера, формирование запроса;
обработка ответа и запуск загруженных Lua-модулей;
исходные перехваты tostring/loadstring, Panorama, renderer и ffi.cast.
54 постоянных XOR-блока заменены проверенными открытыми строками.
C-объявления раскрыты. JavaScript часов свёрнут в return Date.now();
внешняя обёртка сохраняет подмену часов на 0 и для этой читаемой формы.
Имена восстановлены по назначению. value_N_M/argument_N_M — обычные
локальные переменные; pack_return_values сохраняет nil в возвратах.
Авторские имена и комментарии неизвестны.

ПРОВЕРКИ
200 проверок кодеков/хэшей против исходной VM и Python-эталонов;
3 сравнения запуска загрузчика/HTTP-границы на Lua-заглушках FFI;
9 сравнений внешней обёртки; 3 проверки JavaScript часов.
В тестах нет реальных HTTP-запросов и доступа к памяти процесса.
Синтаксис итогового LuaJIT проверен. Работа в игре не проверялась.
Совпадение на заглушках не доказывает совместимость всех игровых ABI.
Не заявляется восстановление отсутствующего серверного приложения.

ЗАВИСИМОСТИ
GameSense CS:GO, ffi, gamesense/http, panorama, renderer, client,
readfile, json и родные интерфейсы конкретной версии игры.
Серверная проверка использует длину readfile(_NAME..'.lua'); размер
восстановленного файла отличается от оригинала. Рабочая авторизация
и загрузка внешнего приложения этим восстановлением не подтверждены.

ДЛЯ ОТСУТСТВУЮЩЕГО ОСНОВНОГО ПРИЛОЖЕНИЯ
Нужны module.txt и/или сохранённые Lua-ответы, которые загружались
при работе оригинала. Этот архив содержит только восстановленный код
и отчёт; оригинал и исследовательские материалы сюда не включены.
