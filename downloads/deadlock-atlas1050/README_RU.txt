Deadlock / AtlasOS на Windows 10
GTX 1050 2 ГБ, i5-4590, 16 ГБ RAM, выходное разрешение 1440x1080, Discord открыт.

КАК ЗАПУСКАТЬ
1. Распакуй архив. Открой Steam под своей обычной учётной записью Windows.
2. В свойствах Deadlock в Steam убери старые параметры запуска, особенно
   -vulkan, -high, -threads и другое разрешение: они могут конфликтовать.
3. Закрой Deadlock обычным способом, если он уже открыт. Discord можно оставить.
4. Дважды нажми Deadlock_Atlas_1050.bat. Администратор не нужен.
5. Пункт 1 — без ограничения FPS. Пункт 2 — лимит 60 FPS для проверки плавности
   с Discord. Лимит не гарантирует, что система сможет удерживать 60 FPS.
6. Пункт 3 — откат изменений Windows, сделанных этим батником.
   Пункт 4 — сведения о системе. После запроса запуска окно можно закрыть.
   Откат лучше делать после закрытия игры; выбор GPU применяется при новом запуске.

ЧТО ДЕЛАЕТ БАТНИК
- Находит Steam и Deadlock по библиотекам Steam и appmanifest_1422450.acf.
- Передаёт через Steam: -dx11 -fullscreen -w 1440 -h 1080 +fps_max 0 (или 60).
- Выключает два существующих пользовательских параметра захвата Game DVR.
  Если Atlas уже удалил/выключил их, повторной оптимизации здесь не будет.
- Для найденного EXE задаёт Windows предпочтение производительного GPU.
  Это помогает выбрать GTX вместо встроенной Intel при наличии такой ситуации;
  само по себе не ускоряет уже выбранную GTX и не меняет профиль драйвера NVIDIA.
- Сохраняет исходные значения перед записью. Повторные запуски не затирают
  исходный снимок. Откат возвращает существовавшие значения и удаляет созданные.
  Каталог: %LOCALAPPDATA%\Deadlock1050Profile — backup.json и profile.log.
  Не удаляй backup.json до отката. Используй тот же аккаунт Windows.

Службы AtlasOS, его план питания, Game Mode, приоритеты/привязку процессов,
защиту, таймеры, сеть, файл подкачки и настройки Discord батник сохраняет.
Кэш шейдеров не очищает, процессы не завершает, программы не скачивает.
Параметры запуска применяются при таком запуске через батник; профиль Steam
и графические конфиги игры он не переписывает. Чтобы убрать заданный лимит,
в следующий раз выбери пункт 1 либо задай fps_max 0 в консоли игры.

ГЛАВНОЕ ДЛЯ FPS НА ЭТОМ ЖЕЛЕЗЕ — НАСТРОЙКИ ИГРЫ
Батник не заменяет выбор графики в меню. Имена пунктов зависят от обновления.
Выставь:
- Выходное разрешение: 1440x1080, 4:3, полноэкранный режим.
- Вертикальная синхронизация: выкл.
- Текстуры: низкие. 2 ГБ видеопамяти быстро становятся ограничением.
- Эффекты, тени и сглаживание: минимум; наиболее тяжёлые эффекты освещения,
  объёмного света и ambient occlusion — выкл./минимум, если доступны.
- Размытие в движении: выкл.
- Масштаб рендера: начни с 70%; рабочий диапазон для сравнения 65–75%.
  Выход остаётся 1440x1080, но внутренняя картинка становится менее чёткой.
  Если доступен апскейлер FSR, сравни его с обычным масштабом рендера.
- Если уменьшение масштаба почти не меняет FPS именно в замесе, вероятен упор
  в CPU/движок. Снижение разрешения не устраняет такой предел i5-4590.
- На GTX 1050 нет DLSS. От батника нельзя ожидать гарантированных 100–144 FPS.

NVIDIA — ПРОФИЛЬ ТОЛЬКО ДЛЯ DEADLOCK
Панель управления NVIDIA → Управление параметрами 3D → Программные настройки:
- Выбери EXE Deadlock из game\bin\win64.
- Режим управления электропитанием: предпочтителен режим максимальной
  производительности. Он может увеличить нагрев/потребление; проверяй частоты.
- Вертикальная синхронизация: выкл. для максимального FPS.
- Фильтрация текстур — качество: высокая производительность, если такой пункт есть.
- Кэш шейдеров: оставь включённым/по умолчанию. Не чисти его перед каждой игрой.
- Если игра предлагает NVIDIA Reflex, сначала сравни включённый Reflex
  с выключенным по задержке и плавности; это не гарантированный прирост FPS.

РАСТЯНУТОЕ 1440x1080 БЕЗ ПОЛОС
Если монитор поддерживает режим: NVIDIA → Регулировка размера и положения
рабочего стола → Масштабирование «Во весь экран», выполнять на GPU.
При необходимости включи переопределение режима масштабирования игр.
Если режим недоступен или игра его игнорирует, сначала выбери поддерживаемое
1440x1080 в меню игры. Батник не создаёт режимы монитора и не меняет его частоту.

DISCORD ОСТАЁТСЯ ОТКРЫТЫМ
- Отключи игровой оверлей Discord и перезапусти Discord после изменения.
- Оставь голос, но выключи чужие видеопотоки/демонстрации и свою трансляцию
  на время проверки FPS. Закрой тяжёлые каналы с GIF/видео, уменьши анимации.
- Аппаратное ускорение сравни в обоих состояниях с перезапуском Discord.
  Выкл. может освободить немного VRAM, но увеличить нагрузку на i5;
  вкл. — обратный компромисс. Универсально лучшего варианта для этой пары нет.
- Если используешь подавление шума Krisp и звук микрофона позволяет,
  сравни нагрузку с более простым подавлением. Шумоподавление расходует CPU.

ПРОВЕРКА РЕЗУЛЬТАТА
Сравни один и тот же участок/сцену с открытым Discord: средний FPS, просадки,
плавность и качество голоса. Запиши масштаб рендера и режим Discord.
Пункт 1 подходит для поиска максимума, пункт 2 — для сравнения с ограничителем.
При невозможности удержать 60 FPS попробуй встроенный лимит 45–50, если игра
его предлагает; ограничитель сам по себе не повышает производительность.
Файл подкачки желательно оставить системного размера, особенно с 16 ГБ RAM
и открытым Discord. Если он уже настроен Atlas, сначала проверь его состояние.

Синтаксис проверен парсером PowerShell 7.4.6; 17 сценариев сохранения, отката
и запуска проверены с имитацией реестра/Steam. Windows PowerShell 5.1,
сама Windows/AtlasOS и Deadlock здесь не запускались. FPS не измерялся.
Наличие параметра в реестре/его отключение не означает измеренный прирост FPS.
