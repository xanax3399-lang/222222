Откройте sigma_source.lua. Это основной файл для чтения и изменения.

СОВМЕСТИМОСТЬ С МЕНЮ GAMESENSE

Ошибка «строка 131: not found» возникала при поиске sv_maxusrcmdprocessticks.
Эта ссылка в приложении не использовалась. Всего убраны 9 неиспользуемых
ссылок; их список есть в menu_dependency_audit.json.

Все оставшиеся 16 зависимостей теперь проверяются перед исходной подменой
panorama.loadstring, расходованием RNG, созданием своего UI, изменением
настроек и регистрацией обработчиков. Проверяется и число возвращённых
handles: например, для Yaw и Body yaw нужны два элемента.
Если обязательных элементов не хватает, в консоль выводится весь список
[sigma] Required/API сразу. Приложение после этого не запускается.
Неожиданные ошибки API тоже попадают в отчёт и останавливают запуск.

Четыре элемента допускают отсутствие: Yaw base, Yaw jitter и Freestanding
body yaw нужны исходнику только для скрытия/возврата видимости; отсутствующие
элементы не трогаются. Для Fake yaw limit пропускаются запись лимита,
видимость и принудительный лимит 30 при крауче за CT. Список отсутствующих
необязательных элементов выводится как [sigma] Optional.
Настоящие handles после проверки сохраняются; повторных поисков в середине
загрузки нет. Вымышленные UI-элементы взамен отсутствующих не создаются.

Это исправление совместимости поверх реконструкции, оно намеренно меняет
поведение загрузки при несовместимом меню. Исходная реконструкция сохранена
в research/sigma_source.recovered.lua, предыдущая версия с одиночным
исправлением Fake yaw limit — в research/sigma_source.ui_compat.lua.
Сравнения с VM ниже относятся к реконструкции до этих исправлений.

Проверка итогового файла использует закрытый реестр допустимых названий меню:
неизвестные пути действительно выдают not found. Воспроизведена ошибка старого
варианта с отсутствующим sv_maxusrcmdprocessticks. Проверены отсутствие всех
неиспользуемых ссылок, всех необязательных элементов, нескольких/всех важных
элементов, неполный набор handles и ошибка API. При отказе проверено отсутствие
изменений UI, регистрации событий, расхода RNG и подмены panorama.loadstring.
При полном меню вызовы API после поиска ссылок совпали с предыдущей версией.
В реальной игре итоговый файл пока не проверялся.

Внутри находится вся извлечённая логика 41 функции присланного приложения:
настройки GameSense, антиаим, выбор целей, обработка попаданий/выстрелов,
ручные направления, freestanding, отрисовка и индикаторы.
Имя исходного файла само по себе не подтверждает наличие отдельного
алгоритма предикта — названия в реконструкции даны по фактическому использованию.

ЧТО ИЗМЕНИЛОСЬ ОТ ПРЕДЫДУЩЕГО ВАРИАНТА

Было 4295 строк, стало 2876. Вместо VM, регистров и фабрик функций —
обычные Lua-функции, лексические замыкания, условия и циклы.
Убраны лишние присваивания, восстановлены прямые тела 13 небольших функций,
9 технических циклов заменены обычными for с проверкой используемых значений.
Повторяющийся сбор нескольких UI-ссылок оформлен функцией reference_group.
Обработчикам событий присвоены имена по их назначению.

Удалены неиспользуемая таблица padding_words и генерация текста. Цикл
из 2000 вызовов math.random оставлен намеренно: он сохраняет состояние RNG,
от которого могут зависеть последующие случайные значения приложения.

Это реконструкция полного тела приложения, а не точный авторский исходник.
Авторские имена и комментарии не восстановлены. В сложных участках остаются
промежуточные value_N и argument_N, назначение которых неоднозначно.
pack_results/unpack_results обслуживают многозначные возвраты Lua;
они не являются виртуальной машиной или потоком скрытых инструкций.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ

Синтаксис: Lua 5.1 и LuaJIT 2.1.
С оригинальной VM совпали запуск с 57 элементами UI/13 регистрациями событий,
42 сценария обработчиков и интерфейса (449 вызовов API вместе с запуском),
344 случая для 13 математических/вспомогательных функций.
Совпали все 2000 случайных выборов и следующий результат RNG.
Отдельно проверены 27 запутанных переходов исходной VM.

Проверки используют фикстуры GameSense, не настоящую игру. Все возможные
ветви исполнения не доказаны, в CS:GO не проверялось. Настоящие HTTP-запросы
и удалённый JavaScript при проверках не выполнялись.
Исходная подмена panorama.loadstring и логика проверки Steam ID сохранены.
Ссылка jok3r.cc/64storage.txt относится к списку Steam ID; тела приложения
были встроены в присланную Lua, они не скачивались с этого сайта.

ВОСПРОИЗВЕДЕНИЕ

В отдельном каталоге с Python установите research/requirements-full.txt:
  python -m pip install -r requirements-full.txt
Затем из research/:
  python rebuild_editable.py

Входной SHA-256 проверяется автоматически. Запуск извлечения выполняется
в урезанной Lua-среде с лимитом инструкций, без файлового и сетевого API.
Указанные результаты относятся к приложенным сценариям; они не заменяют
проверку совместимости с вашей версией GameSense.
