# V2 и V3 для CS:GO

V2 зафиксирована на коммите `72aa34f0956c619ba5f24c9e5c19c6dabf7fd7ff`:

- Ветка: `codex/skeet-v2-stable`.
- Тег: `skeet-v2-stable-72aa34f`.
- Пара DLL + инжектор: [исходный архив v2](https://github.com/xanax3399-lang/222222/releases/download/skeet-v2-nl-points-dll-72aa34f0956c619ba5f24c9e5c19c6dabf7fd7ff/skeet-v2-nl-points-windows.zip).
- Режим запуска: пункт **2**, `NL points`; расчёт тормозного импульса включён
  настройкой `[movement] nl_brake=1` из архива.

Хеш исходного архива и каждого файла записан в `v2-stable.json`. Это запись
уже опубликованных файлов; повторная сборка не подменяет этот архив. Ветка
v2 остаётся на указанном коммите, дальнейшие патчи разрабатываются в v3.

Ветка V3 — `codex/skeet-v3-patches`, её исходная база совпадает с v2.
Первый реализованный патч — дополнительные точки верхней части капсулы головы
из выбранной записи анимации. Режим запуска в новом инжекторе — пункт 3,
внутренний режим 6, CLI `--mode v3-patches`. Пункт 2 остаётся режимом v2.
Список изменений — `v3-development.json`. Это собственная геометрическая
добавка; полный контроллер остановки NL пока не перенесён. Интерполяция и
экстраполяция не менялись. Успешные попадания на карте здесь не проверены.

Публикация v3 должна использовать отдельный тег и архив с именем v3. Существующий
workflow v2 запускается по push только в `codex/skeet-v2-nl-points`; для v3
используется `skeet-v3-patches.yml` с проверками и загрузкой DLL в Windows.

Версия v3 и номер пункта меню — разные значения. У опубликованной v2 пункт 3
по-прежнему включает прежние экспериментальные гипотезы анимации; в новом
инжекторе v3 эти гипотезы перенесены в пункт 6. Старый архив v2 не изменён.
