Stock resolver v1 / GameSense / CS:GO Legacy 8802 / Windows x86

Установка
1. Полностью закройте CS:GO. Распакуйте архив в отдельную папку целиком.
2. Запустите injector.exe. Пункт 2 (также Enter) — штатный GS с новым
   резольвером. Пункт 1 — штатный GS; скрипт в этом режиме не запускается.
3. Инжектор скопирует stock_resolver.lua в папку csgo игры.
4. В меню GameSense разрешите unsafe scripts (нужно для FFI), обновите
   список Lua и загрузите stock_resolver.lua. Это обязательный шаг:
   без Lua-драйвера новый резольвер не применяет решения.
5. Настройки: LUA / B / Stock resolver: enabled. Изначально включён.

Это отдельная экспериментальная сборка. Старые v2/v3 не обновляются.
Используйте skeet.dll, injector.exe и Lua из одного архива.
При обновлении или смене режима нужен полный перезапуск игры.
CS2 не поддерживается. Командный запуск:
    injector.exe --mode stock-resolver
    injector.exe --mode stock
    injector.exe --game "C:\путь\csgo.exe" --mode stock-resolver

Что подключено
C++-модель sr_* скомпилирована непосредственно в skeet.dll.
Lua получает сетевые simtime, eye yaw, LBY, body pose, скорость, duck,
флаги земли, позицию и параметры интерполяции/задержки. Результат C++
применяется через штатные plist Force body yaw / Force body yaw value.
Память ограничена 64 игроками x 16 записей (C++-модель около 102 КиБ).
Повторный simtime не добавляется. Чужой Steam ID в том же слоте, откат
simtime, большой разрыв и телепорт сбрасывают историю. На сетевом обновлении
нет записи файлов, сканирования памяти или перебора всех предыдущих тиков.

Гипотезы -60/0/+60 сравниваются с согласованным движением/LBY и паттерном
чередования yaw; pose имеет слабый вес. Есть накопление подтверждений,
проверка возраста записи и подавление одиночной смены направления.
При слабых данных и в воздухе работает штатный GS. Existing manual/other
script Force body yaw имеет приоритет. При отключении/смерти/выходе
скрипт восстанавливает только свои действующие настройки.
Evidence threshold — оценка согласованности данных, НЕ процент попадания.
Подтверждённое попадание в голову слегка усиливает гипотезу; unknown,
spread и прочие промахи не считаются доказательством стороны резольвера.

Границы реализации
Это самостоятельно написанная эвристика, а не перенесённый NL resolver.
Удалённые usercmd сервер не предоставляет; скрипт их не получает.
Полный native animation state, layers и матрицы костей не реконструируются.
Штатные backtrack, ragebot, урон/hitchance, autostop, DT/recharge сохраняются.
Старые патчи NL points/braking, v3 crown/fire/recharge в режимах 1/2 этой
сборки не устанавливаются, даже если включены в старом INI.

Плавность и отчёты
Show frame-time metrics показывает текущие активные overrides / игроков,
p95 времени кадра за последние 512 кадров и время последнего обновления Lua.
Stable FPS limit по умолчанию ВЫКЛЮЧЕН. При желании включите и выберите
устойчивый для ПК лимит; исходный fps_max восстанавливается при отключении.
Сам по себе лимит не гарантирует плавность и может снизить средний FPS.
Save resolver report and history сохраняет в csgo:
    stock_resolver_report.txt — счётчики и время кадра/обновления;
    stock_resolver_history.csv — до 16 последних записей каждого игрока.
Отчёты также сохраняются при выгрузке скрипта. Постоянного файлового лога нет.
Пункт 5 инжектора показывает старые статусы загрузчика; для нового резольвера
используйте кнопку в Lua. Папка reports архива содержит проверки сборки.

Проверено автоматически: C++-модель, строгая LuaJIT-связка с реальной C++
библиотекой, Windows x86 LoadLibrary собранной skeet.dll и её sr_* вызовы,
производственные выключатели старых патчей, установка Lua и CLI инжектора.
Показатели host benchmark относятся к машине CI, не к вашему i5-4590.
Игровая точность, выигрыш FPS и отсутствие рывков в матче ещё не проверены.
