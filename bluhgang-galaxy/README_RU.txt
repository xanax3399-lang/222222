BLUHGANG V2 GALAXY — исправление совместимости меню

Замените старую Lua файлом bluhgang_v2_galaxy_fixed.lua. Одновременно старую
и исправленную версию не загружайте.

Исправлена ошибка строки 37: отсутствующий Fake yaw limit проверяется,
запись/скрытие пропускаются с предупреждением. Собственные настройки этого
лимита в меню Lua не меняют отсутствующий нативный ползунок.
Аналогично обработан отсутствующий sv_maxusrcmdprocessticks: соответствующие
изменения лимита команд пропускаются. Для DT/BAIM добавлен поиск RAGE/Aimbot
после RAGE/Other; при отсутствии индикаторы/проверки их состояния не активны.
Убраны неиспользуемые ссылки maxprocticks, player_list, reset_all, apply_all,
dt_limit. При отсутствии Config/Load не регистрируется его callback.
Freestanding поддерживает boolean-чекбокс и старое строковое управление.
Изменения API ограничены локальной таблицей ui этого скрипта.

Проверены синтаксис Lua 5.1/LuaJIT и изолированный блок нативных ссылок,
отсутствие Fake yaw limit/sv_maxusrcmdprocessticks, перенос DT/BAIM,
запись Freestanding в обоих вариантах. Полное выполнение и работа в игре
не проверялись; исходные FFI-зависимости и внешние библиотеки сохранены.

Для повторения проверки: Python с lupa==2.6, затем python verify.py.
