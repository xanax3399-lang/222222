# Состав восстановленного исходника

`outlaw_source.lua` содержит восстановленный код приложения, а не только
лоудер: в текущем файле присутствуют все 386 пронумерованных функций без
пропусков и повторов. Встроенные строки JavaScript и FFI остаются в Lua;
их отдельные копии, 40 пресетов и исторические журналы включены в ZIP.
`outlaw_deobfuscated.lua` — побайтная копия основного Lua.

Это восстановление доступного приложения, а не оригинальный авторский проект.
Наличие всех идентификаторов не доказывает эквивалентность всех ветвей.
Авторские имена и комментарии в обфускации отсутствуют. Внешние библиотеки
GameSense не входят в предоставленный код; их список — `dependencies.json`.
Присланная отдельно обёртка на 9224 байта, подменяющая `require`, не является
полной обфусцированной программой. Она не добавлена и не исполнялась.
Исходный `output_outlaw_beta (1).lua` с хешем из `verification.json` в текущем
наборе файлов отсутствует; повторное сравнение с его VM не проводилось.

## Текущие исправления

Исправлены неверные привязки UI-конструктора, hotkey, обработчиков выгрузки,
списка/импорта/удаления конфигов, проверки выбора UI и pre_render.
Отдельно исправлены чтения настроек из nil, захват изменяемой переменной
вместо контрола Force Defensive для конкретного условия и логические флаги
видимости. HTTP-клиент получил рабочую привязку `_get_header`: заголовок
читается до освобождения запроса; один ответ не вызывает одновременно
успешное завершение и таймаут; удаление не пропускает соседние запросы.

Проверки текущего исправления выполняются через LuaJIT без игры:

```sh
python3 -m pip install -r requirements-test.txt
python3 tests/test_ui_wrapper.py
python3 tests/test_callback_bindings.py
python3 tests/test_http_lifecycle.py
python3 tests/test_startup.py
```

Проверены компиляция обоих Lua, 13 проверок UI-обёртки, привязки конфигов,
7 исходов HTTP-запросов с фиктивными ответами, создание 909 UI-контролов,
4 отложенных инициализатора, 265 UI-обработчиков, 810 вариантов переключения
настроек и 50 вызовов меню/отрисовки/выгрузки после переключений.
Проверки ошибок UI также воспроизводят прежние nil-привязки искусственным
возвратом дефекта в тестируемом фрагменте.

Тестовый API намеренно не исполняет native FFI, игровые интерфейсы и HTTP.
Реальный игровой цикл, Windows/GameSense, внешние библиотеки и протокол
старого загрузчика не проверены. Исторические результаты из
`readable_validation/` относятся к предыдущим версиям, а не к новому запуску.

Для проверки в игре выгрузите все предыдущие копии Outlaw, замените файл
и загрузите одну копию. При новой ошибке необходим полный текст с номером
строки: гарантировать отсутствие ошибок на непроверенных игровых путях
по этим тестам нельзя.
